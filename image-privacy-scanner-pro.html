Free Image Privacy Scanner & Metadata Remover

This browser-based privacy tool checks image metadata that can reveal information about a photograph. It can detect EXIF fields such as GPS coordinates, camera information, capture date, software and other available metadata.

What can photo metadata reveal?

Photos may contain location coordinates, camera model, lens information, timestamps, software names and other embedded information. Before sharing a sensitive image online, scanning its metadata can help you understand what information is attached to the file.

Private browser processing

The scanning and cleaning logic runs in your browser. Your selected images are not intentionally uploaded to a Toolz server. GPS reverse-geocoding is only performed when you explicitly use a location lookup and requires an external map service request.

How the cleaner works

The cleaner creates a fresh browser-generated image copy rather than modifying the original file. This normally removes source EXIF metadata from the generated copy. Always verify the output when handling highly sensitive files because browser image formats and metadata support can vary.

Frequently asked questions

Does this scanner upload my photos? The scanner and cleaning process are designed to run in your browser. Images are not intentionally uploaded to a Toolz server.

Can it detect GPS coordinates? If GPS data is embedded and readable in EXIF metadata, the scanner can detect latitude and longitude.

Can I scan many images? Yes. Select multiple supported images to scan them together and download cleaned copies as a ZIP.
