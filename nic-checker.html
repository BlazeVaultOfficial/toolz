What is the International ID Checker?

The International ID Checker is a browser-based utility for checking supported identity number formats from different countries. Select a country, enter its relevant identification number, and the tool analyzes only information that is actually encoded or mathematically derivable from that number.

Supported Countries

  • 🇱🇰 Sri Lanka NIC — birthday, gender, age and old-format voter letter.
  • 🇮🇳 India Aadhaar — format check only; Aadhaar is a random number and personal details are not decoded from the number.
  • 🇨🇳 China Resident ID — birth date, gender and administrative division code.
  • 🇰🇷 South Korea Resident Registration Number — birth date and gender; current numbers do not expose the old regional code.
  • 🇯🇵 Japan My Number — format check only; personal attributes are not decoded from the number.
  • 🇵🇹 Portugal Citizen Card — document-number structure check.
  • 🇺🇸 USA Social Security Number — format and structural checks only.
  • 🇨🇦 Canada SIN — format and checksum validation.
  • 🇬🇧 UK National Insurance Number — format and prefix/suffix structure check.

No Fake Information

Not every national identification number contains a person's birthday, gender, town or address. When information is not encoded in the selected ID number, this tool clearly displays "Not encoded in ID" instead of guessing or inventing a result.

Privacy

This tool is designed to process the entered number locally inside the browser. It does not require an account and does not need a government database connection to perform format or structural decoding.
