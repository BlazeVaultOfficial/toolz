IP Address Checker

An IP address is a numerical address used for communication over an IP network. This tool validates IPv4 and IPv6 addresses and can request your public IP from a public IP service when you choose “Use My Public IP”.

  • IPv4: checks four-part IPv4 notation and numeric ranges.
  • IPv6: checks full and compressed IPv6 notation.
  • Public IP: requests the public IP returned by the selected external service.
  • No signup: no account is required to use the checker.

What can you check?

IPv4 ValidationCheck whether an address follows valid IPv4 notation.
IPv6 ValidationCheck full and compressed IPv6 addresses.
IP VersionIdentify whether a valid address is IPv4 or IPv6.

How to use the IP Checker

  1. Enter an IPv4 or IPv6 address.
  2. Press Check IP.
  3. Or press Use My Public IP to request your current public IP.

IP Address Checker FAQ

What is an IP address?
An IP address is an address used for communication over an IP network.

Can this tool find my exact location?
No. This page does not determine an exact physical location from an IP address.

Does an IP address identify a person?
An IP address generally identifies a network connection or address allocation; additional information is needed to associate it with a particular person.

What is the difference between IPv4 and IPv6?
IPv4 uses 32-bit addresses, while IPv6 uses 128-bit addresses.
